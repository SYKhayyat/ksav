# Ksav Torah lexicon — hand-curated supplement
#
# The generated lexicon (lexicon.txt) is built from Public Domain texts: Mishnah,
# Shulchan Arukh, Mishnah Berurah, Rashi. That corpus covers Mishnaic and
# halachic Hebrew well, but it cannot cover two things a bochur writes constantly:
#
#   1. Talmudic Aramaic and the vocabulary of lomdus. Sefaria carries no Public
#      Domain Hebrew Talmud (William Davidson is CC-BY-NC, Wikisource CC-BY-SA),
#      so the Gemara's own words never enter the corpus.
#   2. The citation apparatus of later acharonim — שו"ע, מהרש"א, נפק"מ, ודו"ק —
#      which postdates the printed editions we draw from.
#
# Those are exactly the words a general Hebrew dictionary also rejects, so
# without this file the checker would underline the terms that matter most.
# Everything here is written unpointed with ASCII gershayim, matching the
# normalization the checker applies before lookup.
#
# Edit this file by hand. It is not regenerated.
