# Ksav English lexicon — hand-curated supplement
#
# The generated lexicon (lexicon-en.txt) is the English Speller Database plus the
# Public Domain Judaic English that Sefaria carries. Between them they cover
# general English and biblical proper nouns well. They cannot cover the one
# vocabulary this product's writers use in every paragraph: contemporary
# transliterated Hebrew, Aramaic and Yiddish. Nothing public domain contains it,
# because the writing that uses it is all in copyright.
#
# Without this file the checker is the mirror image of Hspell — excellent on
# ordinary prose and useless on the sentence someone actually wanted to write.
# "The Rambam paskens that one may not daven Mincha after shkiah" is nine words,
# five of which a general English dictionary rejects.
#
# Two rules govern what goes in here.
#
#   1. **Everything is lowercase.** In this checker a lowercase entry accepts
#      every capitalisation of itself and a capitalised entry rejects the
#      lowercase form (see engine/src/spell/english.rs). Transliterated words
#      have no settled capitalisation convention — people write "the Gemara" and
#      "learning gemara", "on Shabbos" and "erev shabbos" — so insisting on one
#      would underline correct spellings over a style choice. That is the failure
#      mode that teaches people to ignore every squiggle. ESDB's own entries keep
#      their real casing, because English proper nouns do have a convention.
#
#   2. **Variants are words.** There is no standard transliteration: Shabbos,
#      Shabbat and Shabbes are the same day, and which one someone writes says
#      where they learned, not whether they can spell. Every spelling in common
#      use is listed. The cost is that a genuine typo which happens to be another
#      community's spelling gets through — the same trade the Hebrew side makes
#      with prefix stripping, and the same one every checker makes.
#
# Nothing here is derived from any copyrighted word list. It is written out of
# the vocabulary itself, and it is covered by Ksav's own licence.
#
# Edit this file by hand. It is not regenerated. `cargo test -p ksav-engine
# spell_en` fails on any entry the generated lexicon already accepts, so it
# cannot quietly fill up with words that are carrying no weight.
